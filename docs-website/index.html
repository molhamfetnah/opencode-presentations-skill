🚀 Quick Start

Up in 30 seconds.

Install, create, preview. Three commands and you're looking at your first slide.

# Clone and install
git clone https://github.com/molhamfetnah/opencode-presentations-skill.git
cd opencode-presentations-skill && npm install

# Create your first presentation
node presentations/bin/present create "My Talk" --style=glassmorphism

# Preview with live reload
node presentations/bin/present preview my-talk.md --port=3000
