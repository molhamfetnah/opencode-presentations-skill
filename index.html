🛠️ Built for Developers

A Presentation Tool That
Respects Your Workflow

Command-line interface, version control friendly, and extensible. Built by developers who were tired of fighting with slide software that gets in the way of actually communicating ideas.

🎨

20 Professionally Crafted Design Styles

From glassmorphism to brutalist, from corporate blue to terminal. Each style has been thoughtfully designed for specific contexts — whether you're presenting to executives, teaching a class, or documenting an API. Pick a style that fits your audience.

🔤

Full Bidirectional Text Support

Arabic, Hebrew, Farsi — complete right-to-left text treatment with proper direction handling. Includes 49 Google Fonts pre-configured with proper ligatures, kerning, and regional character support for authentic typography.

⚡

Real-Time Live Preview

Edit your Markdown and watch changes appear instantly. Hot reload keeps your creative flow while you iterate. No context switching, no waiting for exports. Your slides update as you type.

📊

Interactive Charts & Carousels

Built-in ApexCharts integration for data visualizations. Five carousel types — coverflow, parallax, timeline, and more — ready to drop into any presentation with simple Markdown syntax.

🤖

AI-Powered Image Generation

Generate images directly within your slides using AI. Free tier via Pollinations, or plug in your own OpenAI or similar API key for higher volume. Integrates seamlessly into your Markdown workflow.

📐

Five Slide Aspect Ratios

16:9 (widescreen), 4:3 (traditional), 1:1 (square), 9:16 (vertical stories), and 21:9 (ultrawide). Choose the format that matches your delivery platform and audience.

🔧

Interactive Wizard & CLI

Not sure where to start? The built-in wizard guides you through theme selection, style customization, and output format. Or use the CLI directly for scriptable, repeatable workflows.

📦

Export to HTML & PDF

Generate self-contained HTML presentations or export to PDF with a single command. Perfect for sharing via email, hosting on your site, or archiving for future reference.

🚀 Quick Start

From Installation to Your First Slide
in Under 30 Seconds

Install the package, create your presentation, preview it live. Three commands — that's all it takes to create your first professional presentation.

# Step 1: Clone the repository
git clone https://github.com/molhamfetnah/opencode-presentations-skill.git
cd opencode-presentations-skill && npm install

# Step 2: Create your first presentation
# The wizard will guide you through theme and style selection
node presentations/bin/present create "My Talk" --style=glassmorphism

# Step 3: Preview with live reload
# Opens at http://localhost:3000 — changes update instantly
node presentations/bin/present preview my-talk.md --port=3000
